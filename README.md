# Game

## Concept: Shadow Signal

Shadow Signal is a turn-based competitive mind game built around prediction, bluffing, and counter-play. Each round, both players secretly choose one action, then reveal at the same time. The goal is to out-think the opponent over several rounds instead of relying on fast reactions or random luck.

## Why this game fits

- **PvP first:** the main mode is one-vs-one matches.
- **Play with friends:** invite-based private matches let friends challenge each other directly.
- **Play when nobody is online:** a rules-bound computer opponent uses the same information and action limits as a human player.
- **Fair play:** there are no hidden bonuses, extra AI information, or pay-to-win mechanics.
- **Mind game focus:** winning depends on reading patterns, setting traps, and adapting to habits.

## Core gameplay

Each turn, both sides secretly pick one of a small set of actions:

- **Probe** - gather points safely
- **Guard** - block an expected attack
- **Strike** - punish a greedy Probe
- **Feint** - beats Guard but loses to Probe

Because actions resolve simultaneously, every choice becomes a prediction problem:

- Will the opponent play safely?
- Are they expecting aggression?
- Are they repeating a habit on purpose to bait a counter?

Matches are short, replayable, and easy to understand, but the layered reads and counter-reads give them long-term depth.

## Fairness rules

- The AI never sees the player's hidden choice before reveal.
- The AI is limited to the same action set and win conditions as humans.
- Ranked or competitive play should use deterministic rules with no stat advantages.
- Match history can be shown after rounds so players can learn patterns without exposing hidden information mid-turn.

## Popularity potential

Shadow Signal is designed to be easy to pick up and fun to share:

- fast matches for repeat play
- strong “one more round” feeling
- spectator-friendly reveals
- simple rules with high strategic depth
- good fit for friendly rivalries and online PvP
